# TrakHound.Hosting.AspNetCore

Contains classes for hosting TrakHound Apis in ASP.NET Core outside of an Instance (ex. mapping the Endpoints and Streams of the Controllers).

TrakHound.Hosting.AspNetCore is part of the [TrakHound Framework](https://www.trakhound.com), a modular .NET platform for building and hosting Apis, Blazor Apps, Functions, Workers, Services and Identity providers as packages that run in a TrakHound Instance.

## Installation

```
dotnet add package TrakHound.Hosting.AspNetCore
```

The quickest way to start a package is with the TrakHound templates, which reference the matching version of the libraries:

```
dotnet new install TrakHound.DotNet.Templates
```
