# TrakHound.Blazor.Hosting

Contains classes for implementing .NET Blazor Hosting in the TrakHound Framework.

TrakHound.Blazor.Hosting is part of the [TrakHound Framework](https://www.trakhound.com), a modular .NET platform for building and hosting Apis, Blazor Apps, Functions, Workers, Services and Identity providers as packages that run in a TrakHound Instance.

## Installation

```
dotnet add package TrakHound.Blazor.Hosting
```

The quickest way to start a package is with the TrakHound templates, which reference the matching version of the libraries:

```
dotnet new install TrakHound.DotNet.Templates
```
