# TrakHound.AspNetCore

Contains the ASP.NET Core classes shared by the TrakHound Instance and the debug hosts (ex. the WebSocket and Server-Sent Events Stream handling).

TrakHound.AspNetCore is part of the [TrakHound Framework](https://www.trakhound.com), a modular .NET platform for building and hosting Apis, Blazor Apps, Functions, Workers, Services and Identity providers as packages that run in a TrakHound Instance.

## Installation

```
dotnet add package TrakHound.AspNetCore
```

The quickest way to start a package is with the TrakHound templates, which reference the matching version of the libraries:

```
dotnet new install TrakHound.DotNet.Templates
```
