# TrakHound.Common

Contains the core classes of the TrakHound Framework (the Client, Apis, Apps, Functions, Workers, Services, Packages and Configurations) used by the Instance and by every package.

TrakHound.Common is part of the [TrakHound Framework](https://www.trakhound.com), a modular .NET platform for building and hosting Apis, Blazor Apps, Functions, Workers, Services and Identity providers as packages that run in a TrakHound Instance.

## Installation

```
dotnet add package TrakHound.Common
```

The quickest way to start a package is with the TrakHound templates, which reference the matching version of the libraries:

```
dotnet new install TrakHound.DotNet.Templates
```
