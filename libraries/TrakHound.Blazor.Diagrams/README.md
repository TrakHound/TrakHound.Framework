# TrakHound.Blazor.Diagrams

Blazor diagramming components used by the TrakHound Instance's Admin interface (the Routing editor and the Zone Map).

This library is a copy of [Z.Blazor.Diagrams](https://github.com/Blazor-Diagrams/Blazor.Diagrams) by zHaytam, with its namespaces changed to `TrakHound.Blazor.Diagrams` and modified for TrakHound. It's included as source so the Instance doesn't reference the NuGet package. It isn't published as a package.
