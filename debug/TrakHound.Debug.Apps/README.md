# TrakHound.Debug.Apps

Contains classes for debugging .NET Apps in the TrakHound Framework.

TrakHound.Debug.Apps is part of the [TrakHound Framework](https://www.trakhound.com), a modular .NET platform for building and hosting Apis, Blazor Apps, Functions, Workers, Services and Identity providers as packages that run in a TrakHound Instance.

## Installation

```
dotnet add package TrakHound.Debug.Apps
```

The quickest way to start a package is with the TrakHound templates, which reference the matching version of the libraries:

```
dotnet new install TrakHound.DotNet.Templates
```
