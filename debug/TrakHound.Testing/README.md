# TrakHound.Testing

Contains classes for unit testing TrakHound packages without an Instance (an in-memory Client and the Instance's module creation).

TrakHound.Testing is part of the [TrakHound Framework](https://www.trakhound.com), a modular .NET platform for building and hosting Apis, Blazor Apps, Functions, Workers, Services and Identity providers as packages that run in a TrakHound Instance.

## Installation

```
dotnet add package TrakHound.Testing
```

The quickest way to start a package is with the TrakHound templates, which reference the matching version of the libraries:

```
dotnet new install TrakHound.DotNet.Templates
```
